## Overview

This project focuses on building a machine learning model to classify Iris flowers into three species — Setosa, Versicolor, and Virginica — using a Decision Tree Classifier. It utilizes the well-known iris.csv dataset, which contains measurements of sepal length, sepal width, petal length, and petal width for 150 flower samples. The model is trained on this dataset using the scikit-learn library, allowing it to learn patterns and make accurate predictions based on input features. The project includes steps for loading and preprocessing the data, training and testing the model, evaluating its performance, and optionally visualizing the decision tree to understand how the classifier makes decisions.

## Installation Instruction

**installing IDE**

- *install [Python](https://www.python.org/downloads/windows/)*
- *install [Visual Studio Code](https://code.visualstudio.com/download)*

**Create and Activate a Virtual Environment**

```bash
python -m venv env  # where ene is environment name
```
**Activate the Environment**
For windows
```bash
\env\scripts\activate
```
For macos
```bash
python3 -m venv env
source env/bin/activate
```
**installing libraries**

```bash
pip install pandas scikit-learn matplotlib notebook
```

**🚀 Running the Project**
1.Launch Jupyter Notebook
```bash

```

2. Open and Run the Notebook
    In the browser window that opens, navigate to:
    Iris-Flower-Classification.ipynb

    Open the file and run each cell to execute the code step by step. shift + enter is the shortcut for the executing the each cell
